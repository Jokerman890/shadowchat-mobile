# ADRs

This directory contains architecture decision records for ShadowChat.

Planned initial ADRs:
- ADR-001: Native UI plus shared Matrix core
- ADR-002: Username-first identity model
- ADR-003: Notification privacy model
- ADR-004: Secure storage and recovery model
- ADR-005: Dependency policy for iOS and Android

Each ADR should describe:
- decision
- context
- rationale
- tradeoffs
- consequences
